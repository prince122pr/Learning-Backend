# 🛡️ Authentication, Authorization & JWT Explained

---

## 🔑 What is a Token?

A token is a unique string that represents the identity of a logged-in user.
It is generated by the server and sent to the client after successful login.
It is used to access protected routes or resources without logging in again.

---

## 🧾 What is JWT (JSON Web Token)?

JWT is a popular token format used for authentication & authorization.
It is compact, URL-safe, and digitally signed using a secret key or public/private keys.

Structure of JWT:
- Header → contains algorithm & token type
- Payload → contains user data (e.g., userId, role, email)
- Signature → ensures the token hasn't been tampered with

---

## 🛠️ How JWT Works (Step-by-Step)

1️⃣ User logs in with valid credentials
2️⃣ Server verifies user & generates a JWT signed with a secret key
3️⃣ Server sends the JWT to the client (browser/mobile)
4️⃣ Client stores the token (usually in localStorage or cookies)
5️⃣ For every request to protected routes:
    → Client sends the token in request headers (usually as Authorization: Bearer <token>)
    → Server verifies the token using the secret key
    → If valid → grant access
    → If invalid/expired → deny access

---

## 🔐 Secret Key

A secret key is a private string known only to the server.
It is used to sign and verify JWTs.
If someone changes the token, the signature won’t match → verification fails.
This ensures the token is secure and untampered.

---

## ✅ Authentication vs Authorization
- **Authentication** → Who you are (e.g., verifying your identity using username/password).
- **Authorization** → What you can access (e.g., roles/permissions after login).

---

## 🧠 Middleware (User-Defined)
Custom middleware in Express is a **function** that runs between a request and a response.  
Example: JWT verification, logging, error handling.

---

## 📦 Cookie in HTTP
A **cookie** is a small piece of data stored in the client (browser) and **sent with every HTTP request** to the server.

## 📦 What is `cookie-parser`?
`cookie-parser` is a middleware for Express.js used to **parse cookies** from the HTTP request and make them easily accessible through `req.cookies`.

## ✅ Why Use It?
- To **read cookies** sent by the client (browser).
- To **extract token/session** stored in cookies.
- Helpful in authentication with **JWT stored in cookies**.

- JWT = format of the token (with header, payload, and signature)
- Secret Key = used to verify authenticity of token
- Token is stored on client side, not in DB
- Used in every request to avoid hitting DB repeatedly
- Auth: who are you?
